How it works

Build an order of battle, put the units on the map, and move them through time. Everything you make is kept in your browser; nothing leaves your computer unless you export or share it.

Getting started

Open one of the battle maps on the front page to see how a finished scenario looks, or choose Create new scenario.

  1. Give the scenario a name and a description.
  2. Add the sides and their top units. Each side's standard identity (friend, hostile, neutral…) sets the colour and shape of its symbols; you can change icons and echelons later.
  3. Set the start time and time zone. For a historical battle, use the real date and the local time zone.
  4. Choose the symbology standard (MIL-STD-2525 or APP-6) and click Create scenario.

The map

The editor has a sidebar on the left, the map in the middle and a details panel on the right.

Sidebar

  • ORBAT: the units of each side as a tree. Drag units to reorder them or change their parent.
  • Layers: map features you draw, and background layers.
  • Graphics: control measures (boundaries, phase lines, objectives and the like) to place on the map.
  • Settings: scenario settings, symbol sizes and custom symbols.

Units on the map

Drag a unit from the ORBAT onto the map to place it at the current time. Move the time forward with the timeline at the bottom and drag the unit again: its track between the two times is recorded, and playback animates it. Right-click the map or a unit for more actions.

Map toolbar

Measure distances and areas, show unit tracks, draw features and switch on a reference grid. Range rings, orbit mode and narration (text or recorded audio attached to scenario events) are in the map's controls.

Organization charts

Chart mode turns a unit hierarchy into an organization chart. Pick the root unit in the ORBAT panel, then use Chart settings for page size, layout, labels, symbols and connectors. Export chart saves it as PNG (1×–3×) or SVG.

Grid editing

Grid mode shows the units as a spreadsheet, for editing names, symbols, equipment and personnel quickly across many units at once.

Text to ORBAT

Type or paste an order of battle as indented text, one unit per line; indentation makes the hierarchy. Unit types and echelons are recognised from the names ("1st Infantry Division", "2/34th Line Regiment"), and you can add your own patterns. The result can be copied, dragged into a scenario, opened in the editor or exported.

Import

Choose Import data from the File menu, or drop a file on the map. Load from a file, a URL, a scenario kept in your browser, or pasted text; the format is usually detected for you.

  • Scenario files (.json): import a side or group into the current scenario. By default, units with the same ID are updated rather than duplicated; Replace entire side/group removes units the file doesn't have.
  • GeoJSON, MilX, and Excel/CSV tables (map the columns, then build the hierarchy).
  • ORBAT Builder and Order of Battle Generator files, and DATE force structures.
  • KML/KMZ files load as map layers.

Export

Choose Export scenario from the File menu. Formats: scenario file (.json), GeoJSON, KML/KMZ, MilX and XLSX.

For a scenario file you choose which sides, groups and layers go in, so you can give each player only what their side would know. A snapshot of a group keeps only where its units are at that moment, not their plans or history: useful for showing a side the enemy units it has spotted. Save your choices as a preset to reuse them each turn.

Share

Share online

  1. Open the scenario, then File → Share scenario online…
  2. Optionally switch on Encrypt scenario and set a password. The scenario is encrypted in your browser (AES-GCM); only people with the password can open it. The description is not encrypted.
  3. Click Upload and generate link, then Copy Link.

Share as a URL

Small scenarios can be packed into the link itself, with nothing uploaded. Very long links may not survive email or chat, so use online sharing for anything large.

Saving and backups

Your scenarios are kept in your browser's storage on this computer, not online.

Your browser's storage is not a backup. Clearing site data, or the browser running short of space, deletes your scenarios. Download them regularly: File → Save writes a .json file you can open again by dropping it on the page.

Custom symbols

When the standard military symbols aren't enough, add your own: Settings tab → Custom unit symbols → Add. Give a name and an image as a URL or a data URL. PNG or SVG with a transparent background works best. A data URL stores the image inside the scenario file, which keeps the file self-contained but makes it larger; an ordinary URL must allow cross-site loading, and you need permission to use the image.
